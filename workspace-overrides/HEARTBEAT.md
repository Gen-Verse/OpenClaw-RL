# HEARTBEAT.md - Autonomous Heartbeat Tasks

## Periodic Checks

- Review pending tasks in task queue
- Check for new messages or notifications
- Verify system health (gateway status, model availability)
- Update memory files with recent activity
- Organize workspace (clean temp files, update docs)

## Status Report Format

When heartbeat fires, report:
- Tasks completed since last heartbeat
- Any errors or issues encountered
- System health status
- Next scheduled actions
